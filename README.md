# 🦺 Behavior-Based Safety (BBS) Analysis Dashboard

An interactive Excel dashboard project focused on analyzing **workplace safety observations**, monitoring **safe** and **unsafe** behaviors, and identifying areas that require attention to improve workplace safety compliance.

## 📌 Project Overview

This project involves analyzing workplace safety observation data collected through a Behavior-Based Safety (BBS) checklist.

The original dataset contained multiple safety inspection measures spread across numerous columns. Before performing the analysis, I used **Power Query** to clean, restructure, and transform the data into an analysis-ready format.

The final dataset covered **292 safety observations across 605 employees**, enabling an organized analysis of safety performance across different workplaces, observation categories, and inspection measures.

The **objective** was **to transform raw safety checklist data into meaningful insights** that can help monitor workplace safety practices and identify potential areas of concern.

## 🎯 Business Objectives

- Monitor safe and unsafe workplace behaviors.
- Evaluate safety compliance across different workplaces.
- Identify safety categories with higher unsafe observations.
- Analyze safety performance across individual inspection measures.
- Compare observations across observers and workplace locations.
- Identify areas that may require additional safety training or corrective action.

## 🔄 Data Preparation & Transformation

Data preparation was a major part of this project because the original checklist data was spread across multiple columns.

The following steps were performed:

1. **Data Inspection:** Examined the original safety checklist structure and identified the measures requiring transformation.
2. **Data Cleaning:** Cleaned and standardized the source data using Power Query.
3. **Unpivoting:** Converted multiple safety inspection columns into a structured row-based format.
4. **Safety Classification:** Standardized the safe and unsafe responses using a classification mapping.
5. **Category Mapping:** Consolidated 32+ individual checklist measures into 10 broader safety categories using a mapping table.
6. **Data Structuring:** Prepared the transformed dataset for analysis and dashboard development.

## 📊 Key Analysis Areas

The dashboard focuses on the following areas:

- 🦺 **Overall Safety Performance:** Monitoring safe and unsafe observations.
- 🏭 **Workplace Analysis:** Comparing safety performance across different workplaces.
- 📋 **Category-Level Analysis:** Evaluating safety performance across 10 consolidated categories.
- 🔍 **Inspection Measure Analysis:** Identifying specific checklist measures associated with unsafe observations.
- 👥 **Observer Analysis:** Examining observations recorded by different observers.
- 📈 **Compliance Monitoring:** Understanding patterns in workplace safety observations.
